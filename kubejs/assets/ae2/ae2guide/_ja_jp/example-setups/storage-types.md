# いろいろなストレージとネットワークの整理

フィルター、[区分け](../items-blocks-machines/cell_workbench.md)、[ストレージの優先度](../ae2-mechanics/import-export-storage.md#storage-priority)を使うと、
いろいろなものに合わせてストレージを何段階かに分けられます。

ストレージの種類はだいたい次のとおりです:
* 一般のストレージ。数個から数千個しかない雑多なもの全部用です。4k や 16k などの小さな[セル](../items-blocks-machines/storage_cells.md)を
使います。
* 大量のストレージ。丸石や鉄など、数千個より多くあるもの用です。256k や MEGA アドオンのセルなど、大きなセルを
使います。
* 農場の局所ストレージ。[専用の局所ストレージ](specialized-local-storage.md)や
[いろいろな](simple-certus-farm.md)[ケルタス](semiauto-certus-farm.md)[農場](advanced-certus-farm.md)で説明しているものです。

優先度は、メインのネットワークにアイテムが入れられたら、まず専用の大量ストレージや局所ストレージに入れようとし、
(フィルターや区分けのせいで)それができなければ一般のストレージに入れるように設定します。
つまり、アイテムがあるストレージから別のストレージへ**自分から移動することはなく**、ネットワークに出入りするうちに「移っていく」ということです。
自分から移したいときは <ItemLink id="io_port" /> を使います。

        大事な注意: ドロワーのような大きくて最適化された入れ物ならよいが、巨大チェストのようにスロットが多くて*最適化されていない*
        大きな入れ物にストレージバスを使うと、動作がとても重くなる。
    </BoxAnnotation>

    <BoxAnnotation color="#33dd33" min="11 0 3" max="12 1 4" thickness="0.05">
        大量のストレージ。この例では、優先度の高いドライブに入れた、区分けした 256k セル。このセルは
        丸石と鉄に区分けしている。均等分配カードが入っているので、丸石だけで埋まって鉄の入る場所が無くなることはない。
        ドライブの優先度が高いので、丸石や鉄がネットワークに入るたびにここへ行き、
        丸石や鉄をネットワークから取り出すときは*ここ以外の全て*から取り出されるので、丸石と鉄はこのセルに「移っていく」。
    </BoxAnnotation>

    <BoxAnnotation color="#33dddd" min="11 0 5" max="12 1 6" thickness="0.05">
        一般のストレージ。この例では、16k セルでいっぱいのドライブ。セルは区分けしていない。ドライブの優先度は中立
        (この例では 0)なので、何かがネットワークに入ると、まず専用の大量ストレージや局所ストレージへ行き、
        ネットワークから取り出すときはまずここから取り出されるので、専用のストレージがあるアイテムは自然に
        一般のストレージから「出ていく」。
    </BoxAnnotation>

    <BoxAnnotation color="#88ff88" min="11 0 8" max="12 1 9" thickness="0.05">
        この入出力ポートは、ネットワークを整理しておくのに大事な役割を果たす。ストレージの優先度はアイテムを*自分から*
        動かさないので、一般のストレージのセルはときどき入出力ポートに通して「かき混ぜ」、専用のストレージに
        置き場所があるアイテムをそこへ移すとよい。これでストレージが「デフラグ」され、同じものがあちこちに
        保管されることがなくなる。
    </BoxAnnotation>

    <BoxAnnotation color="#dd3333" min="14 0 11" max="15 1 12" thickness="0.05">
        モブトラップの局所ストレージ。このドライブには、骨や矢など、取っておきたいドロップに区分けしたセルを入れている。
        ドライブ自体には優先度を付けない。優先度に効くのは、メインのネットワークからサブネットにアクセスしているストレージバスだからだ。
        セルには均等分配カードとあふれ破棄カードを入れている。
    </BoxAnnotation>

    <BoxAnnotation color="#dd3333" min="14 1 10" max="15 2.3 11" thickness="0.05">
        モブトラップの局所ストレージ。このストレージバスとインターフェースの組み合わせで、メインのネットワークからこのサブネットのストレージを使える。
        ストレージバスは優先度を高くし、サブネットのセルに保管するものに絞り込んでいる。

        大事: サブネットにゴミ箱の仕組みがあるので、このストレージバスは必ず絞り込むこと。そうしないと
        *ネットワークに入るアイテムや液体などを片っ端から*捨て始める!
    </BoxAnnotation>

    <BoxAnnotation color="#dd3333" min="14 0 9" max="15 1.3 10" thickness="0.05">
        モブトラップの局所ストレージ。物質凝縮機に付けたこのストレージバスは、ドライブより優先度を低くしている。つまり、
        ドライブのセルに入れられないモブのドロップはここへあふれ、処分される。これは、ほとんど壊れた弓のような
        雑多なガラクタでサブネットが詰まるのを防ぐために大事だ。
    </BoxAnnotation>

    <BoxAnnotation color="#dd33dd" min="8 1 11.7" max="9 2.3 13" thickness="0.05">
        スイカ農場の局所ストレージ。いろいろなケルタス農場の例と同じような方法を使っている。サブネットのストレージバスが
        育てたものを樽に入れる。メインのネットワークのもう1つのストレージバス(スイカの薄切りに絞り込み、
        優先度を高くしている)で、メインのネットワークから育てたものを使える。
    </BoxAnnotation>
