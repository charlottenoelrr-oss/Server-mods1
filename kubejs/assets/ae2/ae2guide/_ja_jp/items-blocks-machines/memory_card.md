# メモリーカード

<ItemImage id="memory_card" scale="4" />

メモリーカードは、AE2 の[デバイス](../ae2-mechanics/devices.md)の間で設定をコピー&ペーストしたり、
[P2P トンネル](p2p_tunnels.md)をつないだりするのに使います。デバイスに[アップグレードカード](upgrade_cards.md)を貼り付けることもできます。

- シフト+右クリックで設定をコピーするか、P2P の新しい接続周波数を作ります。
- 右クリックで設定、アップグレードカード、接続周波数を貼り付けます。
