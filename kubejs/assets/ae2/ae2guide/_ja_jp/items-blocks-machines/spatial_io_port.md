# 空間I/Oポート

<BlockImage id="spatial_io_port" p:powered="true" scale="8" />

空間I/Oポートは[空間 I/O](../ae2-mechanics/spatial-io.md)で[空間セル](spatial_cells.md)を入れておき、
空間 I/O の操作を制御するのに使います。

自動化したければ、ホッパーや AE2 のバスなど、どんなアイテム物流でもセルを出し入れできます。
