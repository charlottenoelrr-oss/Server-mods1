# Advanced AE!

Advanced AE は、ME システムを扱うときの使い心地を良くし、終盤の仕組みでできることを広げることに力を入れています。
このMODでは、パターンプロバイダーを強化して相手の機械の特定の面にアイテムを送れるようにしたり、クラフトストレージに
空きがある限り、コプロセッサを共有しながら無制限の数のクラフトを実行できる複数ブロックのコンピューターを作ったりできます。
他にも便利な追加がたくさんあります!
